# Vocario · aggiornamenti

Qui vengono pubblicati gli aggiornamenti di **Vocario** e i rinnovi degli abbonamenti.

- Contiene solo file firmati digitalmente: nessun codice sorgente, nessun dato dei clienti.
- I programmi Vocario installano un aggiornamento solo se firma e impronta SHA-256 corrispondono.
- `licenze.json` elenca codici di licenza firmati: senza la chiave privata non si possono creare né modificare.
